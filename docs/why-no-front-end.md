# Views without a front end

Affiliate operators make decisions from source records, agreements and evidence. The database holds those records, the CLI makes changes, and branded HTML gives the operator a readable review pack. There is no server to keep running for the local base.

A conventional application gives people authenticated logins, mobile forms, live collection, notifications and partner self-service. These are not present here. A coding agent runs the documented commands on the operator's machine. It needs trusted access to the owner connection, and it can edit code and records if permitted.

The static dashboards are private snapshots. Regenerate them after changes. Nothing in them changes a record or collects a click. No tracking or payment service is included. Enterprise DNA can build a web front end and connections around this database after agreeing requirements and acceptance checks.

Use `/new-view` for a read-only report. Use `/customise` for a schema or rule change with a migration, source notes and tests. Keep the same database and one command library for every coding agent.
